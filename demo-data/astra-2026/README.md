# Astra 2026 live import pack

Upload these files together in Ripple's Live mode. They intentionally contain one late venue change that Ripple should detect and propagate through capacity, production, signage, catering, calendar, and attendee communication.

The canonical structured version also lives in `src/lib/data/astra.ts` so the “Load Astra pack” action works without filesystem access in the deployed app.

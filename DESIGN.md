# Ripple design system

Ripple should feel like a calm operations room: serious enough for consequential work, warm enough to invite daily use, and clear enough to explain why the system believes something.

## Visual language

- **Deep evergreen `#174D3C`** anchors navigation, primary actions, and trust.
- **Change orange `#E66432`** appears only where attention or propagation matters.
- **Warm paper `#F3F1EB`** replaces generic white/gray software backgrounds.
- **Ink `#18201E`** carries the main text; muted text uses `#66706C`.
- Display headings use a restrained editorial serif. Interface copy uses Geist. Evidence labels and timestamps use Geist Mono.
- Corners stay modest at 6–12px. Shadows indicate layers such as a drawer or modal, not ordinary cards.

## Signature interaction

The vertical impact trail is Ripple's defining component. A changed fact sits at the top, followed by connected consequences. Each consequence must show its evidence, severity, and owner. Suggested actions never execute without a human confirmation.

## Product rules

1. Show evidence beside every AI conclusion.
2. Distinguish detected facts, inferred impacts, and approved actions.
3. Use orange sparingly so a change remains visually meaningful.
4. Prefer progressive disclosure over dense dashboards.
5. Every primary demo action must have visible feedback and a reversible next step.
